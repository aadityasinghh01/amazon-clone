# Amazon Clone

A responsive Amazon homepage clone built with HTML, CSS and JavaScript. It recreates the main layout of amazon.com, and its category and navigation links open the real Amazon site.

**Live demo:** https://aadityasinghh01.github.io/amazon-clone/

## Features

- Top navbar with the Amazon logo, delivery location, search bar, account and cart
- Secondary navigation bar (All, Today's Deals, Customer Service, Gift Cards, Registry, Sell)
- Category bar: Clothes, Health & Personal Care, Furniture, Electronics, Beauty picks, Pet Care, Toys, Fashion
- Hero banner with a "Shop deals in Electronics" link
- Product category boxes with "See more" links to Amazon search results
- Working cart and search using JavaScript
- Multi-column footer with "Back to Top"
- Responsive layout that works on desktop and mobile
- Clickable links connected to the original amazon.com

## Tech Used

- HTML5: page structure
- CSS3: layout, styling and responsive design
- JavaScript: interactivity (cart and search)
- GitHub Pages: hosting

## Run Locally

```bash
git clone https://github.com/aadityasinghh01/amazon-clone.git
cd amazon-clone
```

Then open `index.html` in your browser. No installation is needed.
